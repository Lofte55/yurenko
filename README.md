# YURENKO — сайт

Статический многостраничник. Сборка из `pages/` + `partials/` скриптом `tools/build.mjs`.

## Сборка

```
npm run build
```

Скрипт разворачивает каждую страницу из `pages/*.html` по маршруту из META-блока,
генерирует `sitemap.xml` и `robots.txt`.

## Структура

- `pages/` — контент страниц (META + `<main>`). **Редактировать нужно здесь.**
- `partials/` — head, шапка, подвал. Общие для всех страниц.
- `assets/css/base.css` — дизайн-система (токены, компоненты, анимации).
- `assets/css/generator.css` — стили визарда ТЗ.
- `assets/js/app.js` — навигация, reveal-анимации, счётчики, аккордеоны, формы.
- `assets/js/generator.js` — генератор технического задания.
- `api/submit.js` — приём заявок (Telegram + Resend).
- `tools/build.mjs` — сборщик.

Сгенерированные `index.html` в корне и в папках маршрутов **править не нужно** —
они перезаписываются при сборке.

## Переменные окружения (Vercel)

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота для уведомлений |
| `TELEGRAM_CHAT_ID` | чат, куда падают заявки |
| `RESEND_API_KEY` | ключ Resend для писем |
| `MAIL_FROM` | адрес отправителя, например `site@yurenko.ru` |
| `MAIL_TO` | куда дублировать заявки, можно несколько через запятую |
| `ALLOWED_ORIGIN` | `https://yurenko.ru` |

Без Telegram и Resend формы отвечают успехом, но ничего не доставляют —
настройте хотя бы один канал перед запуском.
